Platform Used: Render

For this practice, I deployed my Node.js application using Render. I used Render because it was simpler than AWS Elastic Beanstalk and worked well with my project setup. I added a server.js file and package.json file so my dashboard could run as a Node/Express application.

The main steps I followed were creating a Render web service, connecting my project files, setting the build command to npm install, and setting the start command to node server.js. After deployment, I opened the live Render URL in my browser to make sure the application was running correctly.

I did not run into any major issues, but I made sure the start command and project files matched what Render needed to run the app.
